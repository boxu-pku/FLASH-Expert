# IO 输入输出单元（§9）

> **TL;DR**：FLASH IO 支持 HDF5（serial/parallel）、PNetCDF、direct FORTRAN、Chombo 四种后端，每种多路适配 Grid 类型（PM/UG）。IO 实现必须与 Grid 匹配——setup 阻止不兼容组合。输出 4 类文件：checkpoint（双精度，restart）、plotfile（单精度，可视化）、颗粒文件、flash.dat（积分量）。`plot_var_#` 选输变量，HDF5 serial 为默认。

## 1. IO 实现矩阵（表 9.1）

| 实现路径 | Grid | 模式 |
|---|---|---|
| `IO/IOMain/hdf5/parallel/PM` | PARAMESH | 并行 HDF5（MPIIO） |
| `IO/IOMain/hdf5/parallel/UG` | UG | 同上 |
| `IO/IOMain/hdf5/parallel/NoFbs` | UG NoFbs | 同上 |
| `IO/IOMain/hdf5/serial/PM` | PARAMESH | 串行 HDF5（MPI 收集→proc 0 写） |
| `IO/IOMain/hdf5/serial/UG` | UG | 同上 |
| `IO/IOMain/pnetcdf/PM` | PARAMESH | 并行 PNetCDF |
| `IO/IOMain/pnetcdf/UG` | UG | 同上 |
| `IO/IOMain/direct/PM` | PARAMESH | 各 proc 写独立文件（不推荐） |
| `IO/IOMain/direct/UG` | UG | 同上 |
| `IO/IOMain/chombo` | Chombo | Chombo 原生 HDF5 格式 |

## 2. Setup 快捷方式

| 快捷 | 展开效果 |
|---|---|
| `+hdf5typeio`（默认） | HDF5 + 衍生数据类型 IO |
| `+parallelio` | HDF5 parallel + PM |
| `+pnetcdf` | PNetCDF + PM |
| `+ug` | UG + HDF5 serial/UG |
| `+noio` | 不含 IO 单元 |
| `+nofbs` | UG NoFbs + HDF5 parallel/NoFbs |

## 3. 输出文件

| 文件类型 | 精度 | 用途 | API |
|---|---|---|---|
| Checkpoint `.chk` | 双精度 (8-byte) | Restart 完整状态 | `IO_writeCheckpoint` |
| Plotfile `.plt` | 单精度 (4-byte) | 可视化/分析 | `IO_writePlotfile` |
| Particle file `.part` | — | 粒子数据 | `IO_writeParticles` |
| `flash.dat` | 文本 | 积分量（质量/能量/动量） | 自动 |

**输出触发方式**：时间间隔、步数间隔、wall-clock 间隔、宇宙学红移间隔、`.dump_checkpoint`/`.dump_plotfile` 强制文件、`tmax`/`nend` 终止时。

**Checkpoint 参数**（表 9.2）：`checkpointFileIntervalStep/Time/Z`、`wall_clock_checkpoint`、`rolling_checkpoint`（上限滚动）、`restart`、`checkpointFileNumber`。

**Plotfile 参数**（表 9.3）：`plot_var_1..N` 选输变量（**FLASH4 默认不输出任何变量**）、`plotfileMetadataDP`/`plotfileGridQuantityDP` 提升精度。

## 4. Restart 机制

```fortran
restart = .true.
checkpointFileNumber = 12
plotfileFileNumber = 120    ! 防止 plotfile 编号空隙
```

Checkpoint 写入时自动（可选）追加 `restart`/`checkpointFileNumber`/`plotFileNumber` 到 flash.par（`appendParRestart=.true.`）。

## 5. 输出文件名格式

`basenm` 控制前缀。示例：`basenm = "sedov_"` 产生 `sedov_hdf5_chk_0001`、`sedov_hdf5_plt_cnt_0001`。

强制 plotfile 插入 `forced`：`sedov_hdf5_plt_forced_0001`。

## 6. HDF5 衍生数据类型（§9.13）

`+hdf5typeio` 启用衍生数据类型 IO，提高并行输出性能——数据以原生数组类型写入而非逐个变量。FLASH 4.8 默认使用此模式。

**已知陷阱**：`-noclobber` 与 `+hdf5typeIO` 不兼容（§1.3 Known Issues）。

## 7. 其他 IO 格式

- Direct IO：无 HDF5/PNetCDF 时的最后手段，**与 fidlr/sfocu 不兼容**
- Chombo IO：仅 Chombo Grid，格式与标准 FLASH 不同
- PNetCDF：仅 parallel 模式，无 serial 实现
- HDF5 serial：默认（PM+HDF5 serial），通过 MPI 收集到 proc 0
