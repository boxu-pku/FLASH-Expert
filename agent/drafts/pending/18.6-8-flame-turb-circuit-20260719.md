# 火焰 / 湍流测量 / 电路（§18.6-18.8）

> **TL;DR**：三个轻量级源项单元：**Flame**（KPP 反应-扩散火焰锋面模型，用于 Ia 超新星 deflagration）、**TurbulenceMeasurement**（湍流统计诊断）、**Circuit**（电路网络耦合）。

## 1. Flame（§18.6）

人工反应锋面模型（ADR advection-diffusion-reaction），用于模拟次网格引爆锋面。

### 1.1 控制方程

进度变量 φ（0=燃料，1=灰烬）：

$$\frac{\partial\phi}{\partial t} + \mathbf{v}\cdot\nabla\phi = \kappa\nabla^2\phi + \frac{1}{\tau}R(\phi)$$

KPP 项：$R(\phi) = \frac{1}{4}\phi(1-\phi)$，对称低阶 → 声学噪声极低。收敛保证：$s$ 为传播速度 → $\kappa \equiv s\Delta x/16$，$\tau \equiv \Delta x/16s$。

### 1.2 子单元

| 子单元 | 用途 |
|---|---|
| `FlameSpeed/Constant` | 常数锋面速度 |
| `FlameSpeed/laminar` | 层流等离子体速度 |
| `FlameSpeed/turbulent` | 湍流增强（TFI 模型） |
| `FlameEffects/BurnParametric` | 参数化能量释放 |

## 2. TurbulenceMeasurement（§18.7）

在线计算湍流统计量（速度色散、功率谱等）的诊断单元。不修改流体状态，仅收集统计数据。

## 3. Circuit（§18.8）

耦合外部电路网络（如 RL 回路）求解器，用于 MHD 模拟中的电流驱动。
