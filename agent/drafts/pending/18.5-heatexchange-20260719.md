# 热交换单元（§18.5）

> **TL;DR**：实现 3T 模拟中离子-电子温度平衡，简单松弛定律。5 种实现：Immediate（瞬间完全平衡）、Constant（常数耦合）、ConstCoulomb（常数 ln Λ）、Spitzer（默认 HEDP 推荐）、LeeMore（改进 Coulomb 对数）。Spitzer/LeeMore 通过库仑对数驱动的 $\tau_{ei}$ 指数弛豫。

## 1. 控制方程（式 18.263-18.265）

$$\frac{\partial \rho E_{\text{Ele}}}{\partial t} = \kappa_{i,e}(T_{\text{Ion}} - T_{\text{Ele}}) + \kappa_{e,r}(T_{\text{Rad}} - T_{\text{Ele}})$$

$$\frac{\partial E_{\text{Rad}}}{\partial t} = -\kappa_{e,r}(T_{\text{Rad}} - T_{\text{Ele}})$$

$$\frac{\partial \rho E_{\text{Ion}}}{\partial t} = -\kappa_{i,e}(T_{\text{Ion}} - T_{\text{Ele}})$$

辐射项仅在 legacy gray 辐射扩散中启用；MGD（§25）内部处理发射/吸收。

## 2. 5 种实现

| 实现 | 目录 | 说明 |
|---|---|---|
| Immediate | `Immediate` | 瞬间完全平衡（测试用） |
| Constant | `Constant` | 常数 `hx_couplingConst12/13/23`（测试用） |
| ConstCoulomb | `ConstCoulomb` | 常数库仑对数 `hx_coulombLog`（测试用） |
| **Spitzer** | `Spitzer` | Spitzer $\tau_{ei}$，式 18.270（**HEDP 推荐**） |
| **LeeMore** | `LeeMore` | Lee & More 1984 Coulomb 对数改进（**更准确**） |

## 3. Spitzer 模型（§18.5.1）

平衡时间式 18.270：

$$\tau_{ei} = \frac{3k_B^{3/2} (m_{\text{ion}} T_{\text{ele}} + m_{\text{ele}} T_{\text{ion}})^{3/2}}{8\sqrt{2\pi} e^4 (m_{\text{ele}} m_{\text{ion}})^{1/2} \bar{z}^2 n_{\text{ion}} \ln\Lambda_{ei}}$$

温度更新（式 18.268）：

$$m = c_{v,\text{ele}} / c_{v,\text{ion}}$$

$$T_{\text{ion}}^{n+1} = \frac{T_{\text{ion}}^n + m T_{\text{ele}}^n}{1+m} - m\frac{T_{\text{ele}}^n - T_{\text{ion}}^n}{1+m} \exp\left(-(1+m)\frac{\Delta t}{\tau_{ei}}\right)$$

能量更新用比热（式 18.269）→ EOS 调用取最终温度。

**源码**：$\tau_{ei}$ 计算在 Spitzer 和 LeeMore 各自的 `Heatexchange.F90` 中实现。

Coulomb 对数式 18.271：$b_{\text{max}}$（式 18.272 Debye 长度），$b_{\text{min}}$（式 18.273 经典/量子取大）。默认下限 `logLambdaFloor=1.0`，避免 HEDP 中 $b_{\text{max}} \sim b_{\text{min}}$ 产生小/负值。

## 4. LeeMore 模型（§18.5.2）

与 Spitzer 仅 Coulomb 对数不同（式 18.274 vs 18.271）：

$$\ln\Lambda_{ei} = \frac{1}{2} \ln\left[1 + \left(\frac{b_{\text{max}}}{b_{\text{min}}}\right)^2\right]$$

$b_{\text{max}} = \lambda_{\text{DH}}$（Debye-Hückel 屏蔽长度，含离子贡献，式 18.275）。默认下限 `logLambdaFloor=2.0`（Lee & More 1984 推荐）。

## 5. 参数

| 参数 | 影响 |
|---|---|
| `hx_ieTimeCoef` | 缩放 $\tau_{ei}$ |
| `logLambdaFloor` | Coulomb 对数下限（Spitzer=1.0, LeeMore=2.0） |
| `hx_relTol` | 温度调整容差 → 影响 Heatexchange_computeDt 时间步限制 |
