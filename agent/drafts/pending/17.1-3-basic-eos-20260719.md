# 单温状态方程（§17.1-17.3）

> **TL;DR**：FLASH 的 4 种 1T EOS 实现：**Gamma**（理想气体，γ 常数）、**Multigamma**（多物种各自 γ）、**Helmholtz**（自由能表插值，含电子简并 + 辐射修正）。所有 1T 在 §17.1-3 描述，3T 延伸在 §17.4-6（已转）。

## 1. Gamma Law（§17.2）

Colella & Glaz (1985) 参数化：仅需 2 个绝热指数

$$\gamma_1 = \frac{\rho}{P}\frac{\partial P}{\partial\rho}, \quad \gamma_4 = 1 + \frac{P}{\rho\epsilon}$$

理想气体：$P = (\gamma-1)\rho\epsilon$，$P = (N_A k/\bar{A})\rho T$

正向（ρ→P,T）无需迭代，**极快**。限制：单一 γ，固定 Ā, Z̄。

默认 EOS：`source/physics/Eos/EosMain/Gamma/Config:1-5`。

## 2. Multigamma（§17.2）

混合多个理想气体，加权 γ：

$$\frac{1}{\gamma-1} = \bar{A}\sum_i\frac{1}{(\gamma_i-1)}\frac{X_i}{A_i}$$

**限制**：输出 $P_{\text{tot}}$ 但非各物种分压。3T 版本见 §17.4.2 Multigamma multiTemp（已转）。

## 3. Helmholtz 自由能表（§17.3）

| 特性 | 值 |
|---|---|
| 表文件 | `helm_table.dat`（7.7 MB ASCII, 211×71 网格） |
| 覆盖 | 电子简并 + 电子-正电子对 + 辐射 + 离子（理想气体） |
| 读取 | proc 0 读入 → MPI 广播 → 生成二进制缓存 `helm_table.bdat` |
| 输入 | 必须给初始 T 猜测（加速迭代） |
| Coulomb 修正 | `eos_coulombMult` 控制（ρ-T 区域中修正失效时设为 0） |
| eos 模式 | 所有模式（DENS_TEMP / DENS_IE / DENS_PRES 等） |

**源码**：`eos_readHfet.F90:1-5` 读取 Helmholtz 自由能表。

## 4. Eos_wrapped 间接映射

标准模式：`Eos_wrapped` → `Eos_getData`（block → 向量）→ `Eos` → `Eos_putData`（向量 → block）。`EOSMAP` 声明（VARIABLE 关键字）映射 unk 变量 ↔ eosData 角色。
