# 激光能量沉积单元（Energy Deposition）

> 注：本条目与 `.claude/skills/flash-laser/knowledge/overview.md` 互补，前者侧重概念速览和参数总表，本文则全面覆盖 §18.4 手册的物理模型、算法变体、光束/脉冲设置、3D-in-2D 机制及单元测试。

> **TL;DR**：Energy Deposition 单元用几何光线追踪（离散 ray）模拟激光在等离子体中的传播与逆韧致吸收。支持 Cell Average、Piecewise Parabolic、Runge-Kutta 三种 ray-tracing 算法，同步/异步通信模式，3D-in-2D 圆柱对称，以及 3D 圆柱几何。通过 `+laser` 等 setup 快捷引入，光束/脉冲参数由 Config 的 Python genLines 动态生成。

## 1. 物理原理 / 设计动机

### 1.1 几何光学近似

FLASH 不解 Maxwell 方程组，而用几何光学近似（§18.4.1）。激光波长 $\lambda$ 远小于等离子体密度梯度尺度，故 ray 可看作单位质量粒子在势场中运动：

$$
V(r) = \frac{c^2}{2}\eta(r)^2, \quad
\eta(r)^2 = 1 - \frac{\omega_p^2(r)}{\omega^2} = 1 - \frac{n_e(r)}{n_c}
$$

其中 $n_c = \pi m_e c^2 / (e^2 \lambda^2)$ 是临界密度（式 18.35）。当 $n_e \to n_c$ 时折射率 $\eta \to 0$，ray 发生反射（临界面）。

运动方程（式 18.36-18.38）：

$$
\frac{d^2r}{dt^2} = \nabla\left(-\frac{c^2}{2}\frac{n_e(r)}{n_c}\right), \quad
\frac{dv}{dt} = -\frac{c^2}{2n_c}\nabla n_e(r)
$$

手册假设短距离内 $n_e$ 可泰勒展开至一阶（式 18.39），从而在 Cartesian 下得到解析速度/位置公式（式 18.40-18.41）。

### 1.2 逆韧致吸收

ray 的功率衰减由逆韧致频率 $\nu_{ib}$ 控制（式 18.42）：

$$
\frac{dP}{dt} = -\nu_{ib}(t)P, \quad
\nu_{ib} = \frac{n_e}{n_c}\nu_{ei}
$$

电子-离子碰撞频率 $\nu_{ei}$（式 18.44）：

$$
\nu_{ei} = \frac{4}{3}\left(\frac{2\pi}{m_e}\right)^{1/2}
\frac{n_e Z e^4 \ln\Lambda}{(k_B T_e)^{3/2}}
$$

手册推导了 $\nu_{ib}(t)$ 的有理多项式近似（式 18.53），并用二阶 Gauss 求积计算积分（式 18.59）。

### 1.3 激光能量密度（§18.4.3）

ray 的能量密度 `lase` 变量用 cell 内 ray 能量积分除以 cell 体积计算，用于 plotfile 可视化。需在 Config 中声明 `VARIABLE lase TYPE: PER_VOLUME` 才能输出。

## 2. 源码实际实现

### 2.1 核心调用链

```
EnergyDeposition (主入口)
├── ed_setupBeams           ← 解析 ed_* beam 参数 → 构造 beam 数据结构
├── ed_setupPulses          ← 解析 ed_* pulse 参数 → 构造 pulse 表
├── ed_createRays{2D,3D}Rec ← 根据 beam 网格类型（square/radial/statistical/1D）生成 ray 初始位置/速度
├── ed_traceBlockRays{2D,3D}{Rec,UnRec}
│   ├── ed_inverseBremsstrahlungRate  ← 计算每个 cell 的 νib
│   ├── ed_updatePlasma               ← 沉积能量到 EELE_VAR
│   └── 折射/反射逻辑                 ← ed_gradOrder 控制
└── ed_computeBeamPower     ← 按 pulse 表计算每束 beam 的当前功率
```

| 功能 | 文件:行号 | 说明 |

### 2.3 三种 ray tracing 算法（§18.4.4）

| 算法 | 快捷名 | 基本原理 | 适用场景 |
|---|---|---|---|
| **AVG**（Cell Average） | `+laser` | 用 cell 平均 $n_e$ 和线性梯度；速度/位置按式 18.40-41 更新；逐 cell 步进 | 默认，最快，适合光滑密度分布 |
| **CIPPRT**（Cubic Interp + PPRT） | `+laserCubicInterpolation` | 用三线性插值重建 cell 内 $n_e$ 剖面，piecewise parabolic ray tracing | 精度更高，处理陡峭梯度 |
| **CIRK**（Cubic Interp + Runge-Kutta） | `+laserCubicInterpolationRK` | 同上插值，但用自适应 RK (CashKarp45 等) 积分运动方程 | 最高精度，代价最大 |

**源码验证**：`source/.../Laser/Config` 的 `ed_RungeKuttaMethod` 参数（`Config:105`）支持 5 种 RK 方法：`CashKarp45`（默认）、`EulerHeu12`、`BogShamp23`、`Fehlberg34`、`Fehlberg45`。

## 3. 关键参数

由于参数完备表已在 `flash-laser/knowledge/params.md` 全量覆盖，本节仅列出 §18.4.11 中未在 params.md 单独强调的参数，以及手册特有描述。

| 参数 | 类型 | 默认 | 单位 | 含义 | Config 行 |
|---|---|---|---|---|---|
| `ed_numberOfBeams` | INTEGER | -1 | — | 光束数量（必须 > 0） | `Config:96` |
| `ed_numberOfPulses` | INTEGER | -1 | — | 脉冲数量（必须 > 0） | `Config:97` |
| `ed_maxRayCount` | INTEGER | 100 | — | 单 processor 最大 ray 数 | `Config:95` |
| `ed_cellTimeEnergyDeposition` | BOOLEAN | false | — | true：按 cell 内驻留时间近似 νib（快速）；false：用 2 阶 Gauss 求积（精确） | `Config:78` |
| `ed_laser3Din2D` | BOOLEAN | false | — | 2D RZ 下启用 3D ray 模拟 | `Config:93` |
| `ed_laser3Din2DwedgeAngle` | REAL | 0.0 | 度 | 3D-in-2D 楔形对称半角 | `Config:94` |
| `ed_wavelength_<i>` | REAL | — | cm | 第 i 束激光波长（仅实际使用的 beam 需要） | `Config:265`（genLines） |
| `ed_adjustBeamsTargetIntensity` | BOOLEAN | false | — | 1D/2D Cartesian 下自动调整功率以模仿 3D 柱对称 | `Config:70` |
| `threadRayTrace` | BOOLEAN | false | — | OpenMP 并行 ray loop（setup 时设定，运行时不改） | `Config:140-145` |

## 4. 典型用法

### 4.1 最小 setup 命令

```bash
./setup LaserSlab -2d -auto +cylindrical -nxb=16 -nyb=16 \
  +hdf5typeio species=cham,targ +mtmmmt +laser +mgd mgd_meshgroups=6 \
  -objdir=cases/LaserSlab -parfile=example.par
```

### 4.2 选择不同 ray tracing 算法

```bash
# Cell Average（默认）
./setup ... +laser ...

# Piecewise Parabolic
./setup ... +laserCubicInterpolation ...

# Runge-Kutta
./setup ... +laserCubicInterpolationRK ...

# 异步通信模式（仅 AVG）
./setup ... +asynchLaser ...
```

### 4.3 关键 parfile 片段

```fortran
# pulse 定义：1 条脉冲，3 个 (time,s) 段
```

## 5. 与其他单元的耦合

| 方向 | 关联单元 | 关系 |
|---|---|---|
| 上游（调用方） | Driver_sourceTerms | EnergyDeposition 在 Driver 主循环的 `Driver_sourceTerms` 中被调用 |
| 下游（读取） | Grid | 通过 `Grid_getBlkPtr` 获取 `solnData`，读写 `EELE_VAR`（电子内能） |
| 下游（读取） | Eos（Multitype） | 需要 `TELE_VAR`（电子温度）计算逆韧致吸收率 |
| 下游（可选） | RadTrans/MGD | 3T 模拟中激光沉积到电子能量后需 MGD 辐射扩散耦合 |
| 下游（可选） | Heatexchange | 电子-离子温度平衡在激光沉积后发生 |
| 并行框架 | Grid Particles | ray 跨 cell/block 移动通过 `Grid_moveParticles` 接口实现 |
| 诊断输出 | LaserIO | 可选写 ray 轨迹到 HDF5 plotfile（需 `ed_useLaserIO=.true.`） |

## 6. 常见错误

| 错误信息 | 原因 | 修复 |
|---|---|---|
| `ed_setupBeams: Not enough beam runtime parameters` | `ed_maxBeams` 小于 `ed_numberOfBeams`（setup 变量，非 parfile 参数） | 在 setup 命令加 `ed_maxBeams=<N>` |
| `ed_setupBeams: target semiaxis length <= 0!` | 1D beam + `ed_adjustBeamsTargetIntensity=true` + `targetSemiAxisMajor <= 0` | 设 `targetSemiAxisMajor > 0` 或关 `ed_adjustBeamsTargetIntensity` |
| 编译不含 Laser 相关文件 | setup 命令漏了 `+laser` 或其变体 | 确认 setup 含 `+laser` / `+laserCubicInterpolation` / `+asynchLaser` |
| runtime 读取参数失败 | `ed_numberOfBeams` 或 `ed_numberOfPulses` > 编译时 `ed_maxBeams`/`ed_maxPulses` | 重新 setup + make |

## 7. 已知陷阱 / 与手册的差异

### 7.1 手册页码偏移

手册 §18.4 标注印刷页码 276-318，但 PDF 实际页由于前置页（License + TOC xvi 页）偏移约 18 页。使用 `pdftotext -f` 时，§18.4 实际对应 PDF 页 294-336（已验证）。

### 7.2 `threadRayTrace` 为 setup 变量

手册 §18.4.11.3 将其列为 runtime parameter，但源码 `Config:140-145` 中声明为 setup 变量（不可在 parfile 运行时改）。用户需在 `./setup` 命令行通过 `threadRayTrace=T` 设定。

### 7.3 LaserIO 仅兼容 HDF5

手册 §18.4.11.4 明确指出 LaserIO 仅与 `+parallelIO` 或 `+hdf5typeio` 配合使用。Direct IO 和 PnetCDF 不支持 ray 轨迹输出。

### 7.4 `ed_laser3Din2D` 楔形角单位

手册各处使用"度"，源码确认输入以度为单位（`Config:94` 无 CONVERSION 标注）；内部计算时已转换为弧度。

### 7.5 3D-in-2D 的折射处理（§18.4.8）

手册 §18.4.8 详细描述两种子算法：Exact（正弦周期运动）和 Approximate（假设 $a_R$ 恒定）。实际 Cell Average 算法默认使用 Approximate 版本以降低计算代价。Exact 版本仅在 $n_e$ 梯度严格对称时触发。
