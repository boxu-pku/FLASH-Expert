# 多温 EOS 扩展（§17.4-17.6）

> **TL;DR**：§17.4-17.6 补充 §17.1-17.3（单温 Gamma/Multigamma/Helmholtz）未覆盖的 3T 和 multimaterial 能力。multiTemp 使 EOS 支持离子/电子/辐射三温独立计算；5 种子变体（Gamma/Multigamma/Helmholtz/Tabulated/MatRad3/Multitype）；MultiFluid 用于 VOF 界面捕捉；Multitype(MTMMMT) 混合不同 EOS 类型的材料（Gamma + Tabulated）；Tabulated 读取 IONMIX/SESAME 表。

> **互补声明**：本条目详细覆盖手册 §17.4-17.6 内容，与 `.claude/skills/flash-eos/knowledge/` 中单温 EOS 内容互补。

## 1. 多温拓展概览

3T 模拟中离子、电子、辐射各有独立温度（`TELE_VAR`、`TEION_VAR`、`TERAD_VAR`）和热能（`EELE_VAR`、`EION_VAR`、`ERAD_VAR`）。标准单温 EOS 无法处理此三温解耦，故需 `multiTemp` 子目录下的实现。

**启用方式**：setup 命令加 `+mtmmmt` 或 `+laser` 等快捷方式会自动包含 multiTemp EOS。

**5 种子变体 + 1 个组合变体**：

| 变体 | 目录名 | 适用场景 | 启用方式 |
|---|---|---|---|
| Gamma | `multiTemp/Gamma` | 理想气体 3T（固定 Ā, Z̄） | `+mtmmmt` 默认 |
| Gamma/Ye | `multiTemp/Gamma/Ye` | 同上但 Ā, Z̄ 随 sumy/ye 变化 | 仿真代码初始化 sumy/ye |
| Multigamma | `multiTemp/Multigamma` | 多物种理想气体 3T | 多物种模拟 |
| Helmholtz | `multiTemp/Helmholtz` | Helmholtz 3T | 需显式包含 |
| Tabulated | 无独立目录（由 Multitype 调用） | IONMIX/SESAME 表驱动 | `+laser` 带表格文件 |
| MatRad3 | `multiTemp/MatRad3` | 物质-辐射 3 温耦合 | 辐射流体模拟 |
| Multitype (MTMMMT) | `multiTemp/Multitype` | **混合** Gamma + Tabulated | `+mtmmmt` |

**源码验证**：`source/physics/Eos/EosMain/multiTemp/Config:1-10` 展示 `CHILDORDER Gamma Multigamma Helmholtz MatRad3 Multitype` 的选择顺序。

### 1.1 共同特征

所有 multiTemp 变体支持以下 EOS 模式（表 17.1）：

| 模式 | 输入 | 输出 |
|---|---|---|
| `MODE_DENS_TIE` | ρ, e*, e† | P*, P† |
| `MODE_DENS_TI_EQUI` | ρ, etotal | Tequilibrium (TE+TION=TF) |
| `MODE_DENS_TE_GATHER` | ρ, Te, Ti, Trad | Pe, Pi, Prad, ... |
| `MODE_DENS_TE_SCATTER` | ρ, Pe, Pi, Prad | Te, Ti, Trad (迭代) |
| `MODE_DENS_TE_RECAL` | ρ, Te 更新 → 重算 | Pe, Pi, Prad |

## 2. Gamma 多温实现（§17.4.1）

### 2.1 物理模型

离子 + 电子均作为理想气体（γ=5/3），辐射作为黑体（γ=4/3）。

总压强和内能：

$$P_{\text{tot}} = P_{\text{ion}} + P_{\text{ele}} + P_{\text{rad}}$$

$$\epsilon_{\text{tot}} = \epsilon_{\text{ion}} + \epsilon_{\text{ele}} + \epsilon_{\text{rad}}$$

辐射项（式 17.21-17.22）：

$$P_{\text{rad}} = \frac{a T_{\text{rad}}^4}{3}, \quad \epsilon_{\text{rad}} = \frac{3P_{\text{rad}}}{\rho}$$

### 2.2 运行时参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `gamma` | 5/3 | 所有分量统称 γ（不要改） |
| `gammaIon` | 5/3 | 离子 γ |
| `gammaEle` | 5/3 | 电子 γ |
| `gammaRad` | 4/3 | 辐射 γ |
| `eos_singleSpeciesA` | — | Ā（原子质量单位） |
| `eos_singleSpeciesZ` | — | Z̄（电离度，固定） |

电离度固定——这是 Gamma 变体的主要限制。

### 2.3 Gamma/Ye 子变体（§17.4.1.1）

允许 Ā 和 Z̄ 随空间变化。通过初始化质量标量 `sumy` 和 `ye` 实现：

```fortran
sumy = Σ Yi       ! 式 17.23
ye   = Ye         ! 式 17.24
abar = 1/Σ Yi     ! 式 17.25
zbar = Ye · abar  ! 式 17.26
```

## 3. Multigamma 多温（§17.4.2）

多个材料通过各自 (Ā, Z̄) 贡献到共用离子/电子分量。注意名称易混淆：所有材料的 γ 仍需为 5/3（单原子理想气体）。

**差异**：仅 Ā 和 Z̄ 的计算方式不同（基于质量分数），其余与 Gamma 变体相同。

## 4. Tabulated 表驱动 EOS（§17.4.3）

### 4.1 表格式

支持三种格式：

| 格式 | 用途 | 读取函数 |
|---|---|---|
| IONMIX1 | 不透明度 + EOS | `eos_tabIonmix` |
| IONMIX4 | 同上（扩充格式） | `eos_tabIonmix` |
| SESAME | TEOS 标准格式（303=离子, 304=电子） | `eos_tabReadSesameTables.F90` |

查表变量：$z̄(T, N_{\text{ion}})$, $E_i(T, N_{\text{ion}})$, $E_e(T, N_{\text{ion}})$, $P_i(T, N_{\text{ion}})$, $P_e(T, N_{\text{ion}})$

**重要限制**：Tabulated 目前不单独使用——仅通过 Multitype（MTMMMT）调用，在 `MODE_DENS_TEMP_COMPONENT` 子模式下运行。

### 4.2 SESAME 处理流程

```
eos_tabReadSesameTables.F90
  → 读取 303 (离子) + 304 (电子) 表
  → 截断非物理区域 (P < 0, 固态区)
  → eos_tabEditSesameTables.F90
     → 确定两表的 (ρ, T) 重叠区域
     → 创建 100×100 的细网格 C
     → 双线性插值填充 C
→ 计算电离度（Atzeni & Meyer-ter-Vehn 2004）
```

### 4.3 SESAME 数据格式

- 表 101/102: 注释
- 表 201: Ā, Z̄, ρ₀（固体密度）
- 表 303: 离子 EOS（ndens × ntemp 网格，P + E）
- 表 304: 电子 EOS（同上结构）
- 表 306/400-600: 被 FLASH 忽略

## 5. Multitype / MTMMMT（§17.4.4）

MTMMMT = MultiTemperature MultiMaterial MultiType

**核心能力**：在一个仿真中混合不同 EOS 类型的材料。当前支持：
- Gamma（理想气体）
- Tabulated（IONMIX/SESAME 表）

**工作原理**：
1. 对每种材料按部分密度独立调用 EOS
2. 分压求和 → 总压
3. 比能 × 部分密度 → 能量密度，求和
4. 3T 模式：对离子和电子分量分别执行上述步骤
5. Newton-Raphson 迭代处理以能量/压强为输入的模式

**启用**：setup 命令加 `+mtmmmt`。示例见 `LaserSlab` 算例。

## 6. MultiFluid VOF 界面捕捉 EOS（§17.5）

与 VOF 流体力学求解器（§15.1.4）配合，处理混合 cell 中的多流体力学平衡。

混合 cell 步骤：
1. 对各流体分量各自调用 EOS
2. 若 $P^α \neq P^β$，松弛体积分数 $f^α$ 至力学平衡（式 17.27-17.35）
3. 等效单流体状态：$\rho = Σ f^α ρ^α$, $E = Σ f^α ρ^α E^α$, $\gamma = (Σ f^α / γ^α)^{-1}$

## 7. 使用方式（§17.6）

### 7.1 直接调用 vs Wrapped 调用

| 方式 | 函数 | 数据格式 | 适用 |
|---|---|---|---|
| 直接调用 | `Eos(mode, vecLen, eosData, ...)` | 向量（连续） | 初始化、少量 cell |
| Wrapped 调用 | `Eos_wrapped(...)` | block 切片 | 主循环中大量 cell 更新 |

### 7.2 Helmholtz 表初始化

`helm_table.dat`（7.7 MB ASCII, 211×71 网格）在 `Eos_init` 中由 processor 0 读入并广播。首次读入后生成二进制缓存 `helm_table.bdat`（加速后续 restart）。

### 7.3 单元测试

```bash
./setup unitTest/Eos/Gamma -auto -3d
./setup unitTest/Eos/Helmholtz -auto -3d
./setup unitTest/Eos/Multigamma -auto -3d
```

测试原理：在 `MODE_DENS_TEMP`、`MODE_DENS_IE`、`MODE_DENS_PRES` 三个模式间往返调用，验证 $T$, $P$, $\epsilon$ 的往返一致性。

## 8. 已知陷阱

| 问题 | 说明 |
|---|---|
| Gamma 变体电离度固定 | `eos_singleSpeciesZ` 运行时不改，需要可变电离度则用 Gamma/Ye 或 Tabulated |
| Tabulated 仅通过 Multitype 使用 | 不能在 Config 中单独 REQUIRES Tabulated，必须通过 Multitype |
| SESAME 固态区非物理 | FLASH 自动截断 P < 0 区域；用户应在 `eos_tabReadSesameTables` 看日志 |
| Helmholtz Coulomb 修正 | `eos_coulombMult=0` 禁用修正（当 ρ-T 区域中修正失效时使用） |
| `eintSwitch` 已废弃 | `eint1Switch` 在 multiTemp Config 中被标记 `OBSOLETE` |
| 多物种需 `Simulation_initSpecies` | 每个物种的 A/Z/γ 必须通过 `Multispecies_setProperty` 初始化 |
