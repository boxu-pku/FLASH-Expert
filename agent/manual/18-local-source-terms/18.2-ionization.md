# 电离单元（§18.2）

> **TL;DR**：NEI 非平衡电离单元求解 12 种天体元素（He~Ni）+ H 的逐级电离/复合方程，用于 UV/X 射线谱线诊断模拟。用 Bader-Deuflhard + MA28 解刚性 ODE。需要 Summers (1974) 速率系数文件 `summers_den_1e8.rates`。

**方程**（式 18.24-18.25）：

$$\frac{\partial n_i^Z}{\partial t} + \nabla\cdot(n_i^Z \mathbf{v}) = R_i^Z$$

$$R_i^Z = N_e[n_{i+1}^Z \alpha_{i+1}^Z + n_{i-1}^Z S_{i-1}^Z - n_i^Z(\alpha_i^Z + S_i^Z)]$$

**两种实现**：

| 实现 | 状态 | 说明 |
|---|---|---|
| Nei | **已测试** | 非平衡电离（coronal 近似：碰撞电离 + 自电离 + 辐射复合 + 双电子复合） |
| Eqi | 未测试 | 平衡电离近似 |

**参数**（表 18.1）：`tneimin/max`（T 范围），`dneimin/max`（$N_e$ 范围）。

**使用**：需 `summers_den_1e8.rates` 文件。离子种类由 `Simulation/SimulationComposition/Ionize/SpeciesList.txt` 定义，算例 Config 选择子集。

**已知陷阱**：当前版本电离/复合对能量方程的贡献（式 18.23 方括号项）未计入。

**延伸阅读**：§35.7.1 Neitest 测试算例，`source/Simulation/SimulationMain/Neitest/`。
